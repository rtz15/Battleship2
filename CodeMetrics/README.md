# CodeMetrics

Esta pasta guarda os artefactos da ficha 3 relativos a metricas de qualidade de codigo.

Cada membro do grupo deve guardar aqui os ficheiros resultantes da sua analise do requisito
implementado na ficha 2, usando o ultimo commit antes da respetiva pull request.

Conteudos esperados por membro:
- ficheiro XML exportado pelo MetricsTree
- ficheiro Excel com a analise das metricas
- opcionalmente, imagens dos graficos produzidos no Excel
